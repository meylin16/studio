# **App Name**: El Ahorcado Elegante

## Core Features:

- Phrase Input: Input field for user to enter a word or phrase to be guessed. The phrase is masked and stored for game use.
- Masked Word Display: Display the masked word/phrase, with underscores for each letter and double spaces between words. Provides an input field for letter guesses.
- Hangman Game Logic: Render a hangman figure progressively with each incorrect guess. Display win/loss alerts with a reset button.

## Style Guidelines:

- Primary color: Dark blue (#2c3e50) for a sophisticated feel.
- Secondary color: Light gray (#ecf0f1) for backgrounds and text.
- Accent: Teal (#16a085) for buttons and interactive elements.
- Clean, centered layout for easy readability.
- Simple line icons for visual clarity.
- Subtle fade-in animations for alerts and transitions.
